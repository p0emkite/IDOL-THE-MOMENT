단 한 번 표시되는 코드
코드는 비밀번호와 같아. 타인에게 알려주지 말고 안전한 곳에 저장해 줘. 새 코드를 발급하면 이전 코드는 무효화돼.
02 / RESTORE

다른 기기의 도감 불러오기

이전에 저장해 둔 복구 코드를 입력하면 현재 기기에서도 같은 도감을 사용할 수 있어.

다른 도감을 연결해도 현재 기기의 기존 수집 기록은 별도로 남아 있어. 자동 합쳐지지는 않아.
복구 코드 발급은 선택 사항이지만, 발급하지 않으면 브라우저 데이터 삭제 시 도감을 복원하기 어려울 수 있어.
