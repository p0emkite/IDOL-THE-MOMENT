사진과 그룹 로고를 등록하고, 확정된 ITM 프레임에서 크롭을 조절해 보세요. 공개된 카드는 게임의 카드팩과 도감에 연결됩니다.

관리자 로그인

편집은 미리 체험할 수 있으며, 서버 저장과 공개는 ITM 관리자만 할 수 있습니다.

01 / GROUP LIBRARY

그룹 및 로고

그룹 로고 미등록 — 나중에 추가 가능

컬렉션 / 시리즈 관리

위에서 그룹을 선택한 뒤 이 그룹의 컬렉션을 등록하거나 삭제할 수 있습니다.

컬렉션을 삭제해도 이미 제작된 카드의 시리즈 표기는 유지됩니다. 다만 연결된 카드팩의 필터는 먼저 해제해야 합니다.

팩 관리
PACK LIBRARY

카드팩 종류 관리

3D 팩의 실제 비율에 맞춘 권장 크기는 1024×1538px입니다. 다른 비율의 이미지는 늘리지 않고 중앙을 기준으로 잘라 표시합니다.

팩 이미지를 등록할 수 있습니다.

그룹과 시리즈를 선택하지 않으면 해당 항목은 전체 허용됩니다. 두 조건을 선택한 경우 모두 만족하는 카드만 등장합니다.

등장 그룹
등장 컬렉션 / 시리즈

그룹이나 시리즈를 전부 해제하면 해당 분류의 전체 카드를 허용합니다. ‘전체 선택’은 현재 목록의 항목을 명시적으로 선택합니다.

등급별 등장 확률
확률 합계 100%

합계가 정확히 100%여야 저장할 수 있습니다. 팩에 없는 등급은 추첨에서 제외되며, 남은 확률을 비례 조정합니다.

BGM 목록을 확인하는 중입니다.

02 / CARD EDITOR

카드 정보 및 사진

이 카드는 현재 등록되지 않은 컬렉션에 속합니다. 기존 카드의 표기는 유지되지만 신규 카드 선택 목록에는 나타나지 않습니다.

사진을 드래그해 위치를 조절하고, Alt + 마우스 휠로 확대·축소할 수 있습니다.

UR 획득 시 프레임 없이 표시할 원본 일러스트를 따로 지정할 수 있습니다.

선택한 색을 바탕으로 이름에 반짝이는 금속 그라데이션이 적용됩니다.

04 / RELEASE LIBRARY

제작 카드 목록 0

아직 등록된 카드가 없습니다.

삭제 기능은 관리자만 사용할 수 있습니다. 다른 카드·팩에서 사용 중인 그룹·컬렉션 등은 연결을 정리한 뒤 삭제할 수 있으며, 이미 유저가 보유한 카드는 삭제되지 않습니다. 공개 카드는 등급 N·R·SR·SSR·UR 각 1장 이상 등록된 뒤 일반 팩에 반영됩니다.
